# Data

Esta pasta contém arquivos de entrada para análise.

## Tipos de arquivo esperados

- **Currículo (PDF)** — experiências, habilidades, formação e projetos do Romualdo
- **Certificados de cursos (PDF)** — cursos concluídos, plataforma, carga horária
- **Outros dados relevantes** — arquivos avulsos com contexto útil para os posts

## O que extrair

De cada arquivo, identificar:

- Fatos concretos (cargos, empresas, datas, tecnologias, resultados)
- Conquistas e diferenciais que podem virar post
- Cursos e certificações recentes
- Projetos realizados com impacto mensurável

## Como usar

Os dados extraídos aqui alimentam a criação de posts em `../studio/`.
Sempre que um novo arquivo for adicionado, releia esta pasta antes de criar conteúdo.
