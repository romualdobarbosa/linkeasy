# Conferência de cadastros

Este script compara duas exportações de cadastro e lista o que mudou entre elas: linhas novas, linhas removidas e campos alterados.

Escrevi porque a comparação era feita à mão, toda sexta, e levava a tarde inteira. Agora leva o tempo de rodar o comando.

## Como usar

```
python conferir.py antiga.csv nova.csv
```

O resultado sai em `diferencas.csv`, uma linha por diferença, com a chave, o campo, o valor antigo e o valor novo.

## Limites

O script assume que a chave é a primeira coluna. Se não for, ajuste a variável `CHAVE` no começo do arquivo. Arquivos com mais de alguns milhões de linhas ficam lentos, e para esses eu uso o banco.
