✨ Uma reflexão sobre meu primeiro modelo de previsão de demanda ✨

Quando comecei a estudar machine learning, achava que o modelo era a parte mais importante. Spoiler: não era.

Nos últimos dois meses, desenvolvi meu primeiro modelo de previsão de demanda para um estoque fictício de 120 produtos, como projeto de estudo. E essa experiência foi verdadeiramente transformadora. 💡

Aqui está o que aprendi nessa jornada:

1️⃣ **Os dados vêm primeiro.** Gastei cerca de 70% do tempo limpando e entendendo os dados, sublinhando a importância de uma base sólida.

2️⃣ **Simples funciona.** Uma regressão linear com sazonalidade semanal errou em média 11%, enquanto um modelo mais complexo errou 10%, possibilitando uma escolha mais consciente.

3️⃣ **Comunicar é parte do trabalho.** Um modelo só gera impacto quando as pessoas entendem o que ele faz — e por que podem confiar nele.

Como diz o ditado, “o melhor modelo é aquele que é usado”. Não se trata apenas de acurácia, trata-se de criar soluções robustas que realmente façam diferença.

Estudos mostram que a maioria dos projetos de dados não chega à produção. Por isso, é fundamental ressaltar que o lado humano desempenha um papel crucial nesse processo.

O céu é o limite! 🚀 Vamos juntos?
